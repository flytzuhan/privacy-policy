隐私政策

最后更新日期：2026年4月27日

1. 引言

「飞书文档转存助手」（以下简称"本扩展"）是一款 Chrome 浏览器扩展，旨在帮助用户一键将飞书文档复制到个人云空间。我们深知个人隐私的重要性，本隐私政策旨在向您说明本扩展如何收集、使用、存储和保护您的信息。

使用本扩展即表示您同意本隐私政策的内容。如果您不同意本隐私政策的任何内容，请停止使用本扩展。

2. 信息收集

本扩展仅收集实现核心功能所必需的最少信息：

  • 应用凭证：您主动输入的飞书开放平台 App ID 和 App Secret，用于调用飞书 API 接口。
  • 授权令牌：通过飞书 OAuth 2.0 授权获取的 Access Token 和 Refresh Token，用于代替您的身份访问飞书 API。
  • 当前页面地址：读取您当前浏览器标签页的 URL，用于识别飞书文档并提取文档标识信息。
本扩展不会收集您的浏览历史、键盘输入、鼠标行为、剪贴板内容或其他与核心功能无关的个人信息。

3. 信息使用

您提供的信息仅用于以下用途：

  • 通过飞书 OAuth 2.0 协议完成账号授权和身份验证。
  • 读取当前飞书文档的基本信息（文档名称、文档类型）。
  • 获取您飞书云空间的文件夹列表，供您选择目标保存位置。
  • 将文档复制到您选择的目标文件夹中。
  • 记录您最近使用的文件夹，方便下次快速选择。

4. 信息存储

所有数据均存储在您本地浏览器的 Chrome Storage 中：

  • chrome.storage.local：存储应用凭证（App ID、App Secret）、授权令牌（Access Token、Refresh Token）、令牌过期时间。
  • chrome.storage.sync：存储最近使用的文件夹列表（最多 5 条记录）。
本扩展不会将您的任何数据上传至第三方服务器。所有数据仅保存在您的本地浏览器中。

5. 第三方服务

本扩展仅与以下第三方服务进行通信：

  • 飞书开放平台（open.feishu.cn）：用于 OAuth 授权、令牌刷新、获取文件元数据、文件夹列表查询和文件复制操作。所有通信均通过 HTTPS 加密传输。

本扩展不会向飞书以外的任何服务器发送数据。

6. 数据安全

我们采取以下措施保护您的数据安全：

  • 所有与飞书服务器的通信均使用 HTTPS 加密传输。
  • 授权令牌仅保存在浏览器本地存储中，不会通过网络传输到任何第三方。
  • App Secret 在输入时以密码形式隐藏显示。
  • 您可随时通过"退出登录"功能清除所有授权信息。

7. 权限说明

本扩展请求以下浏览器权限及其用途：

  • identity：用于发起飞书 OAuth 授权流程。
  • storage：用于在本地存储应用配置和授权信息。
  • activeTab / tabs：用于读取当前标签页 URL，识别飞书文档。

本扩展仅在您主动使用时才会激活相关权限，不会在后台持续监控您的浏览行为。

8. 您的权利

您对个人数据享有以下控制权：

  • 查看和修改配置：您可以随时通过扩展内的"设置"功能查看和修改 App ID 和 App Secret。
  • 撤销授权：您可以通过扩展内的"退出登录"功能清除所有授权令牌。
  • 清除数据：您可以在 Chrome 扩展管理页面中清除扩展的存储数据，或直接卸载扩展以彻底删除所有本地数据。
  • 在飞书端撤销：您可以在飞书开放平台的应用授权管理中撤销本扩展的访问权限。

9. 儿童隐私

本扩展不面向 14 周岁以下的儿童。我们不会故意收集儿童的个人信息。如果您发现儿童在未经监护人同意的情况下使用了本扩展，请与我们联系。

10. 政策更新

我们可能会不定期更新本隐私政策。更新后的政策将在本页面发布，并通过修改页面顶部的"最后更新日期"来通知您。继续使用本扩展即视为您同意更新后的隐私政策。
